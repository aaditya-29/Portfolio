  2. 02 April 2025

    Kamiyapp — Skill Sharing Platform

    A structured way to find and book local skilled workers. Requesters and workers move through booking, inspection reports, work tracking, and feedback in one role-based application.

    Java · Spring Boot · Spring Security · Hibernate · MySQL

    GitHub repository ↗ for Kamiyapp — Skill Sharing Platform
    Booking workflow & backend

    Problem

    Local service work often has no structured booking process, no cost estimate before work starts, no record of progress, and no accountability through ratings.

    How it works

    1. A requester searches for a worker by skill and creates a booking request.
    2. The worker accepts the booking and submits an inspection report with the problem, estimated cost, and estimated completion time.
    3. Once the inspection is submitted, work can begin; start and completion times are recorded.
    4. After completion, both parties leave ratings and feedback.

    Backend implementation

    • Layered architecture: Controller → Service → Repository
    • Role-based authentication and authorization for requesters, workers, and admins with Spring Security
    • JPA/Hibernate entity mapping on MySQL
    • Booking lifecycle state handling
    • Email notifications for booking updates and status changes

    Stack

  5. 05 May 2024

    Delivery Route Optimizer

    A desktop route planner for last-mile delivery. A KD-Tree selects the next delivery stop; Dijkstra’s algorithm finds the shortest path to it through a weighted road network.

    Java · Swing · KD-Tree · Dijkstra’s algorithm

    GitHub repository ↗ for Delivery Route Optimizer
    Route-planning algorithm

    How it works

    1. The road network is modelled as a weighted graph of locations around Pulivendula, Andhra Pradesh, using real latitude and longitude coordinates and road distances in kilometres.
    2. A KD-Tree is built over the remaining delivery stops, and a nearest-neighbour search using great-circle distance selects the next stop.
    3. Dijkstra's algorithm computes the shortest path to that stop, and the process repeats until every stop has been visited.
    4. A Swing interface lets the user choose the start point and delivery stops, draws the route on the network, and reports the total distance travelled.

    Stack

    Language
    Java
    UI
    Java Swing
    Data structures
    KD-Tree, weighted graph (adjacency lists), stack
    Algorithms
    KD-Tree nearest-neighbour search, Dijkstra's algorithm
